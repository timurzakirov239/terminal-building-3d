# Интерактивная 3D-модель терминала

Концепция планировки здания: Хлебный проезд, 28/1.

В модели представлены клиентская без компьютеров, четыре кабинета с шестью рабочими местами, кухня, два санузла и проходы. Интерфейс позволяет менять ракурсы и видимость элементов.

Это концепция для обсуждения, а не обмерный или рабочий строительный проект.

## Запуск

Статический сайт без сборки. Откройте каталог через любой HTTP-сервер, например `python -m http.server 8080`, затем перейдите на http://localhost:8080/.

Three.js загружается с jsDelivr, шрифт — с Google Fonts. Для просмотра нужен браузер с WebGL и подключение к интернету.

## Публикация

На Vercel используется тип проекта Other, корневой каталог репозитория и отсутствующая команда сборки. Главная страница — `index.html`.
